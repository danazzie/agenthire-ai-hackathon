# Mutual Stake (AgentHire)

PayPal AI Hackathon — [Build what's next with PayPal and AI](https://paypalaihackathon.devpost.com/)

Both sides put money on PayPal. The clock and the proof decide who gets paid.

The buyer's fee and the seller's bond are **authorized, not captured**. A compiled test (not a chat opinion) decides **capture or void**. The worker can be another agent or a person holding proof up to a camera.

This is a prototype for the sandbox. It is a PayPal authorization hold (up to ~29 days), not legal escrow.
